# Contract fixtures

`pixels/`: the pixel-digest vectors of table-manners v0.1.0 (`vectors/pixels/` in
github.com/markhayden/table-manners), copied unchanged. `digests.json` records each file's
`file_sha256`, so the copy checks itself; `crates/squint-core/tests/image_reference.rs`
reproduces every `pixel_sha256` through squint's own decode path (task 7.2).

`squint/`: squint's conformance fixtures (task 7.10), the description and one `run.json` per
status, generated by `crates/squint-core/tests/contract_fixtures.rs` with the volatile fields
fixed. The test fails when squint emits something else; after a deliberate change, regenerate
with `UPDATE_CONTRACT_FIXTURES=1` and copy the files to table-manners `fixtures/squint/`, whose
tests hold them to the schemas.
